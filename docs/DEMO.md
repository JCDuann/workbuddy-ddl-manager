# DDL 管家 · 基于 WorkBuddy 的虚拟操作演示

双击 index.html，用 Chrome 或 Edge 打开。无需安装、无需服务器或网络，机器人素材已内嵌在网页。

## 推荐演示路线（约3–5分钟）

1. 总览：介绍 DDL 管家如何依托 WorkBuddy 完成收件、管理和提醒。
2. 点击“一键演示全流程”，或在部署模拟中手动完成六步。可暂停自动播放。
3. QQ对话体验：QQ风格会话列表、头像、时间、双侧气泡、正在输入、图片消息、具体DDL卡片及快捷操作。点击“示例截图”选择清晰通知、日期待确认或多节点通知；预览后发送，观看逐步提取和保存。也可以选择、拖入或粘贴本地图片，在预览中填写模拟字段。
4. 定时任务：修改示例时钟，开关或手动运行任务。未连接时只入队；完成部署演示后取得模拟回执，摘要出现在QQ对话中。
5. 系统架构：点击各模块；“追踪一条通知”串起通知、提取、持久化和提醒闭环。
6. 回复格式：18类模板均可点击查看示例卡片。

部署模拟下方可以选择缺少运行环境、QQ授权失败、调度版本不同；点击恢复操作继续。

右上角“演示模式”收起侧栏、扩大画面；再次点击恢复。Esc关闭卡片弹窗并退出演示模式。“重置”清空本次模拟状态，恢复示例任务。

## 演示边界

展示主体是 DDL 管家，它依托 WorkBuddy 的 AI、工具调用与原生调度能力构建。界面参考 WorkBuddy 风格，属于项目演示页面。示例人物、任务、时间、授权图形和平台回执都用于模拟。网页不连接真实AI、QQ或校园官网，不读取本机账号，不安装或修改真实系统文件。

聊天使用预设规则，建议使用页面提示的指令。示例图片和提取字段来自同一预设场景；任意本地图片只用于预览，其模拟字段需要用户填写或修改，不运行真实OCR。支持PNG、JPG、WebP，最大8MB。图片与文件均不会上传到网络。“文件演示”使用虚拟PDF通知，不读取真实PDF。卡片下方的按钮是演示快捷操作，真实QQ仍使用文字回复。部署脚本名称与真实迁移包对应，网页中的点击只展示过程，不运行那些脚本。

模拟状态仅保存在当前页面内，刷新后从初始示例开始。完整文件可以拷贝到其他电脑离线展示。
